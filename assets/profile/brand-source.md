# GitHub profile design notes

The public README is intentionally simple: native GitHub Markdown, no custom banner, cards, icons, counters or decorative separators. This keeps the profile readable in both light and dark mode and works well on mobile.

## Brand

The wording comes from the existing [mervine.dev](https://www.mervine.dev/) identity:

> I build software that makes sense.

The longer website version continues:

> To the people using it. To the engineers maintaining it. To the business it is meant to serve.

The profile uses the shorter line in italics. The original wording has not been replaced by a new slogan.

## Earlier profile assets

The previous SVG headers remain under `assets/profile/` for reference, but they are no longer embedded in the profile README. Their branding was based on the website's existing logo and design system in `MerveilleDivine/mervine-dev`.

The project index uses short, factual descriptions and links. Private-source projects link to their public case studies; public repositories link directly to their code.
